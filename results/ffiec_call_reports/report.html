Batch with_skill invocation pattern: Background-parallel via Task tool: launched 15 Task subagents (one per extract.py call), running concurrently in the background while the main agent's turns themselves stayed sequential. This is where the wall-time win comes from.

Batch wall time is end-to-end session duration; per-file wall time is the sum of 15 independent session durations. Both measure "time to extract the corpus."
