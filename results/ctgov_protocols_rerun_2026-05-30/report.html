Total cost = Claude tokens + LlamaCloud credits (parse + extract, billed per page at $0.00125/credit). no_skill never calls LlamaCloud, so its credit cost is $0. with_skill billed 1,283 pages (extract=agentic, parse=agentic).

Parse cache · cold vs warm latency

The with_skill wall time is dominated by the LlamaCloud parse step, which is cached by document content hash. The same corpus runs faster once the parse cache is warm. Credit cost is identical per pass (billed per page) — only latency changes. There is no API toggle to disable the cache on the extract path (the documented parse_config_id hook 404s), and any change to parse options or tier busts the cache.

The batch speedup (3.2×) is smaller than the per-file speedup because the batch parallelizes parses across Claude Task subagents and carries fixed orchestration overhead the cache can't shrink. Batch wall also mixes in Claude's orchestration, which varies run to run (this pair: cold 2 turns vs warm 2 turns) and LlamaCloud server load — so the per-file probe below is the cleaner measure of the cache effect.
